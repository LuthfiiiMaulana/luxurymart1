## ✨ Features

- **Fully Responsive Layout:** Maximum compatibility across mobile phones, tablets, and desktop screens.
- **Modern Product Catalog:** Clean product cards featuring pricing, categories, and interactive hover states.
- **Interactive Client-Side Logic:** Dynamic UI behavior built purely with vanilla JavaScript.
- **Lightweight Architecture:** Zero external frameworks or build tools required.

## 🛠️ Tech Stack

- **HTML5** — Semantic storefront structure (`index.html`)
- **CSS3** — Custom responsive styling and layout (`style-2.css`)
- **JavaScript** — Interactive storefront logic (`app-1.js`)

## 📋 Prerequisites

Before you begin, ensure you have met the following requirements:

- [Git](https://git-scm.com/downloads "Download Git") must be installed on your operating system.
- Any modern web browser (Chrome, Edge, Firefox, or Safari).

## 🚀 Run Locally

To run **Luxury Mart** locally, run this command on your git bash or terminal:

Linux and macOS:

```bash
sudo git clone [https://github.com/LuthfiiiMaulana/luxurymart1.git](https://github.com/LuthfiiiMaulana/luxurymart1.git)
Windows:

git clone [https://github.com/LuthfiiiMaulana/luxurymart1.git](https://github.com/LuthfiiiMaulana/luxurymart1.git)
After cloning, open the luxurymart1 folder and double-click index.html to launch the website in your browser.
